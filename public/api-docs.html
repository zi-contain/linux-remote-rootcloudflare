远控管理系统 API

通过 API 密钥以编程方式管理主机、下发命令并获取执行结果。所有接口统一以 JSON 格式返回数据，适用于自动化运维、监控集成与脚本编排。

认证方式 Authorization: Bearer <api_key>
基础地址
https://remote-admin.pages.dev
所有请求均需在请求头中携带 API 密钥。点击右上角「生成API密钥」按钮即可创建新密钥（调用 POST /api/admin，action=generate_api_key）。

获取主机列表

GET /api/control?action=list_agents

返回所有已接入的受控主机，按在线状态与最后心跳时间排序。

参数说明
参数位置类型必填说明
actionquerystring是固定值 list_agents
请求示例
HTTP 
GET /api/control?action=list_agents
Authorization: Bearer YOUR_API_KEY
响应示例
JSON · 200 
{
  "agents": [
    {
      "agent_id": "xxx-xxx-xxx",
      "hostname": "web-server-01",
      "ip_address": "1.2.3.4",
      "os_info": "Linux...",
      "remark": "主服务器",
      "status": 1,
      "status_text": "在线",
      "last_seen": "2026-08-16T07:25:28Z",
      "created_at": "2026-08-16T07:25:28Z"
    }
  ]
}

下发命令

POST /api/control

向指定主机下发一条 Shell 命令，返回命令 ID，可用于后续查询执行结果。

参数说明（form-data）
参数类型必填说明
actionstring是固定值 send_command
agent_idstring是目标主机 ID
commandstring是要执行的 Shell 命令
请求示例
HTTP 
POST /api/control
Authorization: Bearer YOUR_API_KEY
Content-Type: application/x-www-form-urlencoded

action=send_command
agent_id=xxx-xxx-xxx
command=ls -la
响应示例
JSON · 200 
{
  "success": true,
  "command_id": 42
}

获取命令结果

GET /api/control?action=get_result&cmd_id=42

根据命令 ID 查询单条命令的执行状态与输出结果。状态值：pending（待执行）、executing（执行中）、completed（已完成）。

参数说明
参数位置类型必填说明
actionquerystring是固定值 get_result
cmd_idquerynumber是命令 ID（由下发命令接口返回）
请求示例
HTTP 
GET /api/control?action=get_result&cmd_id=42
Authorization: Bearer YOUR_API_KEY
响应示例
JSON · 200 
{
  "id": 42,
  "status": "completed",
  "result": "total 8\ndrwxr-xr-x 2 root root 4096...",
  "exit_code": 0,
  "command": "ls -la",
  "executed_at": "2026-08-16T07:25:30Z"
}

获取命令历史

GET /api/control?action=get_history&agent_id=xxx

获取指定主机最近 50 条命令记录，按时间倒序排列。

参数说明
参数位置类型必填说明
actionquerystring是固定值 get_history
agent_idquerystring是目标主机 ID
请求示例
HTTP 
GET /api/control?action=get_history&agent_id=xxx-xxx-xxx
Authorization: Bearer YOUR_API_KEY
响应示例
JSON · 200 
{
  "history": [
    {
      "id": 42,
      "command": "ls -la",
      "status": "completed",
      "result": "...",
      "exit_code": 0,
      "created_at": "2026-08-16T07:25:28Z",
      "executed_at": "2026-08-16T07:25:30Z"
    }
  ]
}

获取单个主机信息

GET /api/control?action=get_agent&agent_id=xxx

根据主机 ID 获取单台主机的详细信息，返回格式与列表中单个 agent 一致。

参数说明
参数位置类型必填说明
actionquerystring是固定值 get_agent
agent_idquerystring是目标主机 ID
请求示例
HTTP 
GET /api/control?action=get_agent&agent_id=xxx-xxx-xxx
Authorization: Bearer YOUR_API_KEY
响应示例
JSON · 200 
{
  "agent_id": "xxx-xxx-xxx",
  "hostname": "web-server-01",
  "ip_address": "1.2.3.4",
  "os_info": "Linux...",
  "remark": "主服务器",
  "status": 1,
  "status_text": "在线",
  "last_seen": "2026-08-16T07:25:28Z",
  "created_at": "2026-08-16T07:25:28Z"

curl 示例

可直接复制使用，请替换 YOUR_API_KEY 与域名
Bash · curl 
# 获取主机列表
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://remote-admin.pages.dev/api/control?action=list_agents"

# 下发命令
curl -X POST -H "Authorization: Bearer YOUR_API_KEY" \
  -d "action=send_command&agent_id=xxx&command=uptime" \
  "https://remote-admin.pages.dev/api/control"

# 获取结果
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://remote-admin.pages.dev/api/control?action=get_result&cmd_id=42"

# 获取命令历史
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://remote-admin.pages.dev/api/control?action=get_history&agent_id=xxx"

# 获取单个主机信息
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://remote-admin.pages.dev/api/control?action=get_agent&agent_id=xxx"
